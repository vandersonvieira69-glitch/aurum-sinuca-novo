# Aurum Sinuca
Protótipo com treino local gratuito e uma base inicial de salas online.

## Render
- Build command: `npm install`
- Start command: `npm start`
- Node.js: 22.x (configurado no package.json)

Rota de teste: `/health`.

Esta primeira versão não tem pagamentos, apostas, contas nem gravação persistente de resultados. As salas são experimentais; a sincronização completa da partida será uma etapa posterior.
